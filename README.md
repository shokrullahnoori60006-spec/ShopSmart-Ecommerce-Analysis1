# ShopSmart E-Commerce Sales Analysis

## Portfolio Project — Data Analysis with Python

### Project Overview
ShopSmart E-Commerce Sales Analysis is an end-to-end business intelligence project built with Python. It analyzes e-commerce orders to understand revenue performance, customer behavior, product performance, payment methods, order status, discounts, ratings, and geographic trends.

### Dataset
- **File:** `orders.csv`
- **Records:** 150 orders
- **Period:** January–December 2024
- **Cities:** 10
- **Product categories:** 5

### Tools & Technologies
Python • Pandas • NumPy • Matplotlib • Plotly • Jupyter Notebook

### Analysis Covered
- Data loading, exploration, and cleaning
- Revenue, discount, and average-order-value analysis
- Customer and product performance
- City and category performance
- Monthly and quarterly revenue trends
- Payment methods, ratings, age groups, cancellations, and returns
- Static and interactive visualizations
- Business insights and recommendations

### Key Business Findings
- **Delivered orders:** 136 of 150 (**90.67%**)
- **Cancellation rate:** **5.33%**
- **Return rate:** **4.00%**
- **Highest-revenue city:** **Karachi — PKR 157,020**
- **Highest-revenue category:** **Sports — PKR 196,270**
- **Best-rated category:** **Books — approximately 4.63/5**
- **Lowest-rated category:** **Home & Kitchen — approximately 3.89/5**
- **Highest quarterly revenue:** **Q4 — PKR 241,975**
- **Top-selling product by units:** **Resistance Bands — 27 units**
- **Most frequently cancelled product:** **Bluetooth Speaker — 3 cancellations**
- **Most common payment method:** **Credit Card — 52 orders**

### Business Recommendations
1. Investigate cancellation and return causes, especially in high-risk cities.
2. Continue promoting strong-performing categories such as Sports.
3. Review customer feedback for Home & Kitchen because it has the lowest average rating.
4. Use monthly and quarterly revenue trends to improve promotional planning.
5. Develop retention strategies for repeat customers.
6. Monitor product-level cancellations to identify fulfillment or product-quality issues.
